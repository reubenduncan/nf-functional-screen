# nf-functional-screen

Nextflow DSL2 screening of predicted proteins for nitrogen-cycle and metal/biocide-resistance homologues, with coordinates on the original contigs. Requires Nextflow 25.10 or newer. This first version implements NCycDB and BacMet experimentally confirmed reference sequences. It does not perform dbCAN, pathway completeness, taxonomy, read abundance or insertion-sequence colocation analysis.

## Inputs

A CSV with `sample,proteins` columns. The protein FASTA must be generated by Prodigal, with standard Prodigal headers containing coordinates and strand. Sample names must be unique and use letters, numbers, hyphens, underscores or dots. The optional `gff` column in the supplied Kenya manifest is retained for subsequent integration, but is not read by this workflow.

Provide three pinned reference assets using `--ncyc_fasta`, `--ncyc_map`, and `--bacmet_fasta`. NCyc must include its non-target homologues. The map identifies nitrogen-cycle references; multiple map labels for one reference are retained as semicolon-separated alternatives; a top hit not in the map is retained as a non-target homologue. For this project the selected references are NCyc `NCyc_100.faa.gz` and `id2gene.map` from commit `4ee9aad986264d79e0763933b4d05b05c31125fe` of qichao1984/NCyc, and BacMet EXP FASTA from commit `2e76ce454c9e5b7353af5b7ed63a196a06960788` of ZhihaoXie/BacMet. Preserve the input files and their checksums with the results.

## Processes

1. `MAKE_DB`: DIAMOND makedb, once per reference.
2. `SCREEN`: DIAMOND blastp of each sample's proteins against each database. Default thresholds are E-value <=1e-5, >=40% identity, and >=70% coverage of both query and reference, retaining one top hit per database. These are screening thresholds, not gene-family-specific validation.
3. `ANNOTATE`: joins hits to Prodigal FASTA header coordinates and attributes; distinguishes NCyc target genes from NCyc non-target homologues. BacMet hits are homologues of experimentally supported reference genes, not experimentally proven resistance in the sample.

## Outputs

Workflow outputs under `--outdir`: `reference_databases/` (DIAMOND databases), `diamond/` (raw alignments, including target titles), `functional_hits/` (one TSV per sample) and `summaries/` (JSON counts). Coordinates are 1-based inclusive and extracted from Prodigal headers. Percent coverages in annotated output are aligned coordinate spans divided by sequence lengths. The best hit can be ambiguous among close references; review competing hits and family-specific thresholds before functional claims. Contig co-location alone does not prove activity, mobility, or common taxonomic origin.

```
nextflow run main.nf -profile singularity \
  --input samples.csv --ncyc_fasta NCyc_100.faa.gz --ncyc_map id2gene.map \
  --bacmet_fasta BacMet_EXP_database.fasta --outdir results
```

The `singularity` profile and `conf/delta2-local.config` support a PBS head job with local task execution; configure the long-running queue and head-job resources in Seqera. Input files and output locations can be S3 URIs where the compute environment has suitable credentials and staging support. For initial validation use `-stub-run` with existing input files.
